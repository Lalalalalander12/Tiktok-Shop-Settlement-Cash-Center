# 万乐 · 产品经理面试主页

面向 TikTok Shop(上海)「商家账单 / 智能经营分析产品经理」岗位的个人面试主页。

## 内容

- **产品介绍**:印尼站商家「结算与资金 · 智能经营分析」产品,包含看懂经营、差异对账、深入经营分析、账本导出、AI 解答五个模块。
- **产品思路**:从「钱到账」到「看懂经营」的三层设计、考核指标(含北极星指标)与第一步取舍。
- **能力匹配**:产品经理所需能力与个人经历的对应。
- **实习经历**:字节跳动 TikTok Shop、小红书、得物等经历时间线。

## 文件说明(共 4 个,一起上传到仓库根目录)

- `index.html`:主页本体,单文件、零依赖。页面内「打开 Demo / 先看我做的产品 Demo」按钮指向同目录的 `demo-cn.html`;「English Demo」按钮指向 `demo-en.html`。
- `demo-cn.html`:产品交互原型 **中文版**,单文件、零依赖,可直接在浏览器打开。
- `demo-en.html`:产品交互原型 **英文版(English)**,单文件、零依赖。
- `README.md`:本说明。

> 三个 HTML 页面都放在同一目录、用相对路径互相跳转,因此无论是本地双击打开,还是部署到 GitHub Pages,Demo 按钮都能正常打开,不依赖任何临时链接、不会过期。

## 如何在线预览(GitHub Pages)

1. 把 `index.html`、`demo-cn.html`、`demo-en.html`、`README.md` 四个文件一起上传到本仓库根目录。
2. 打开仓库 **Settings → Pages**,Source 选择 **Deploy from a branch**,分支选 `main`、目录选 `/ (root)`,保存。
3. 稍等 1~2 分钟,GitHub 会生成 `https://<用户名>.github.io/<仓库名>/` 的在线地址。
4. 打开该地址即可访问主页;点击「打开 Demo」进入中文原型 `.../demo-cn.html`,点击「English Demo」进入英文原型 `.../demo-en.html`。
